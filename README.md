# Alignly
Align text left or right (LTR / RTL) for a whole page or a selected section.

**Chrome / Edge / Brave:** open `chrome://extensions`, enable Developer mode, click "Load unpacked", pick this folder.
**Firefox (128+):** open `about:debugging#/runtime/this-firefox`, click "Load Temporary Add-on", pick `manifest.json`.
To publish on Firefox, zip the folder contents and submit to addons.mozilla.org (change the gecko id first).

Default shortcuts: Alt+Shift+S (flip selection), Alt+Shift+E (flip entire page), Alt+Shift+D (reset all). Editable in Settings.
